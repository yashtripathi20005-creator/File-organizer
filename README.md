# File Organizer

A Python GUI application for organizing and renaming files in a folder with customizable naming patterns.

## Features

- 📁 Select any folder to organize
- 🔍 Preview changes before applying
- 📋 Multiple naming patterns:
  - Custom Pattern
  - Prefix Only
  - Suffix Only
  - Date Only
  - Number Only
  - Prefix + Number
  - Prefix + Date
  - Number + Suffix
  - Date + Suffix
  - Custom + Number
  - Custom + Date
- 📅 Include date in filenames with customizable format
- 🔢 Auto-numbering with configurable start number
- 📎 Keep or remove original file extensions
- 🚀 Multi-threaded for responsive UI
- 📊 Progress indication
